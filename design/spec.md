# dsh-ui-mockup · 设置面板设计规格（M3）

> 依据 2026-08-27 经用户确认的 4 页黑白线框图提炼，是 M3 前端实现代码的唯一依据。
> 线框原稿：`design/images/mockup-1787800477783-ab44a5c8-1.png`（概览）、
> `mockup-1787800493335-0aab7d0c-1.png`（提供方与模型）、
> `mockup-1787800609166-0ade07b8-1.png`（生成偏好）、
> `mockup-1787800624752-1c8f7767-1.png`（生成历史）。

## 1. 视觉基调

- **不做独立风格探索**：视觉完全跟随 DSH 设置窗口既有框架——页面挂在 DSH 设置窗口左导航「UI 草图」入口下；
- 配色、字体、间距全部使用 DSH 主题令牌（CSS 变量），浅/深色自适应；原生控件优先（input / select / button）；
- 线框图中的手绘风仅为布局示意，不进入实现。

## 2. 页面清单与结构

四页共用 DSH 设置窗口骨架：顶部标题「设置」，左侧设置分类导航，右侧内容区。

### 2.1 概览

自上而下：

1. 插件简介文字块（一句话说明插件用途）；
2. 「快速使用」卡片，分三小节（图标 + 小标题 + 两行说明），文案采用实施计划 §6.4.1 修正版：
   - ①何时触发：需求研讨中 agent 会主动提议出草图，也可以直接说「出个草图」；
   - ②如何反馈：生成图下方直接点「确认采用 / 选用第 N 版 / 提交修改意见」，或直接打字说；
   - ③如何锁定：确认后自动提炼进 `design/spec.md`，无需手动操作；
3. 底部状态条：状态圆点 +「当前提供方：DashScope · 凭据已配置/未配置」。

### 2.2 提供方与模型

1. 「提供方」区块：两张横排单选卡片——
   - 「阿里云百炼 DashScope」默认选中（选中态边框加粗 + 右上角对勾），小字注凭据配置状态；
   - 「火山方舟 Volcengine」置灰不可选，注「即将支持」（M4 解锁）；
2. 「凭据」区块：
   - 状态行：绿/红点 + 已配置（含来源层标签：进程环境变量 / DSH 密钥存储 / 项目
     `.env` / `~/.dsh/.env` / 启动环境）/ 未配置；
   - **直接写入入口**：`type=password` 输入框 +「保存（覆盖）」/「清除已存密钥」，
     经 `credential/set|unset` 走凭据服务落到 `~/.dsh/.credentials.yaml`；
     **写入即覆盖、永不回显**——输入框草稿只在本地 state，任何 RPC 响应只含
     `{configured, source, writable}` 三个事实；凭据服务缺席时入口不渲染，
     只读层（进程环境变量）遮蔽时 `describe.writable=false`，输入框替换为
     遮蔽说明（写入不会生效），provider 拒绝写入时返回通用失败文案
     （上游错误原文只记宿主日志，不经 RPC 透传，防错误通道夹带密钥）；
   - 「测试连接」按钮，结果以行内文字反馈（成功 / 缺密钥 / 密钥无效 / 网关不可达 /
     无法判定——未知网关响应归入灰态，不误报成功）；
   - 下方保留四种配置方式清单（按读取优先级排序，任选其一）；
3. 「模型分层默认」表格两行：线框图 → `qwen-image-3.0`、高保真 → `qwen-image-3.0-pro`，
   每行右端**原生下拉**（与「默认尺寸」同款 selectStyle），**只能选预设模型**：
   - 线框图：`跟随提供方默认` / `qwen-image-3.0` / `qwen-image-2.0` / `wan2.7-image`；
   - 高保真：`跟随提供方默认` / `qwen-image-3.0-pro` / `qwen-image-2.0-pro` / `wan2.7-image-pro`；
   - **清单维护入口**（新增模型改这里，下拉自动带上）：
     `packages/tool-ui-mockup/src/client/settings-panel.tsx` 顶部的
     `WIREFRAME_MODEL_HINTS` / `HIGH_FIDELITY_MODEL_HINTS` 两个数组；
     第一项 `''` 表示「跟随提供方默认」，**不得删除或移位**；
     预设之外的模型用工具 `model` 参数显式覆盖（面板不可输入自定义）；
4. 「默认尺寸」一行下拉。

### 2.3 生成偏好

单列表单，自上而下：

| 控件         | 类型              | 初始值               | 说明                      |
| ------------ | ----------------- | -------------------- | ------------------------- |
| 保真度偏好   | 单选 ×2           | 线框图               | wireframe / high-fidelity |
| 目标平台     | 单选 ×2           | Web                  | web / mobile              |
| 一次生成数量 | 方块单选 ×4 (1–4) | 2                    | 越界值禁止提交            |
| 轮询超时     | 数字输入（分钟）  | 10                   | 下限 1 分钟               |
| 限流退避策略 | 只读灰字          | 25 秒 × 2 次（自动） | 写死策略不开放编辑        |

> 输出目录一行已从面板移除：落盘位置由设计资产库接管
> （`$DSH_HOME/mockups/<工作区>/images`），schema 字段保留仅为兼容旧用户层数据。

表单底部：「恢复默认」次级按钮（左）/「保存」主按钮加粗描边（右）。保存成功给出行内成功提示。

### 2.4 生成历史

1. 顶部工具行：搜索输入框（按描述文本过滤，回车触发）+「清空历史」次级按钮
   （确认/取消双按钮二次确认）；
2. 历史列表为横向卡片行（最新在前），**服务端分页 5 条/页**（底部分页器 +
   总数），每行：
   - 左侧缩略图（首图）；
   - 中间两行：描述截断文本；灰色元数据「时间 · 模型 · 尺寸 · 文件数」；
   - 行尾「打开原图」链接式按钮（服务目录内文件）；
3. **风格锚点**：
   - 锚点行右上角旗标「风格锚点」，整行边框加粗；
   - **设锚入口在对话图片卡片**（点哪张设哪张：单图为按钮、多图为下拉选版本），
     历史页只保留「解除锚点」与「打开原图」；锚点不在当前页时提示其所在页并可跳转；
   - 同时只存在一个锚点；锚点指向的记录被清空时锚点一并解除；
4. 无历史时显示空态提示。

## 3. 行为规格

- **锚点联动**：用户确认采用的生成结果可设为风格锚点；此后 `ui_mockup` 调用**未显式传 reference 时自动引用当前锚点**作为参考图（I2I 保持多页风格一致）；显式传入 reference 或解除锚点后不注入；**生效模型为 wan 系等非 qwen-image 模型时跳过注入**并在结果消息中说明（参考图是 qwen-image 系端点的能力边界，注入必然被 Provider 拒绝）；
- **存储位置**：生成图 / 锚点 / 历史集中存于 `$DSH_HOME/mockups/<工作区 slug>/`
  （slug = 工作区绝对路径分隔符转 `-` 并首尾包 `-`，与 DSH sessions 目录一致），
  按 workspaceRoot 隔离、跨会话共享、重启持久；`reference` 参数仍收
  `design/images/…` 语义路径（宿主翻译到资产库）或工作区内自备图的相对路径；
  「输出目录」偏好已由资产库接管（schema 字段保留仅为兼容旧用户层数据）；
- 偏好读写不走 RPC：客户端直接绑定同名 settings 命名空间镜像（settings service 为源，
  cordis.yml 为组合 base 层）；保存前做边界校验（数量 1–4、超时 ≥1 分钟）；
- 清空历史仅截断资产库内 `history.jsonl` 与锚点登记，不删除图片文件本身；
- 历史/锚点数据按工作区隔离（`$DSH_HOME/mockups/<slug>/history.jsonl`），不做跨工作区聚合；
- 历史读取为整文件加载后内存过滤/分页：按会话级数据量（百~千条）设计，超此量级再改流式读取。

## 4. 数据与接口契约（Client→Host）

**偏好读写**：不经 RPC——客户端绑定同名 settings 命名空间镜像（`settingsScope.bind({ namespace: 'ui-mockup' })`），schema/校验由宿主 `PrefsSchema` 统一承担。

**私有 RPC 频道 `/ui-mockup`**（authority: trusted-host；凡涉及工作区的端点，
`cwd` 不在信任源内返回 `UNTRUSTED_WORKSPACE`）：

| 端点               | 入参                                 | 出参                                                                                                                                                                                                     |
| ------------------ | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `overview`         | `{ cwd? }`                           | provider id、凭据三事实（configured/source/writable）、当前锚点文件名（无则 null）                                                                                                                       |
| `credential/set`   | `{ value }`                          | 写入后回凭据三事实（永不回值）；空值 `INVALID_PARAMETER`，存储拒绝 `CREDENTIAL_WRITE_FAILED`（通用文案）                                                                                                 |
| `credential/unset` | —                                    | 清除后回凭据三事实；错误码同上                                                                                                                                                                           |
| `history/list`     | `{ cwd?, query?, page?, pageSize? }` | `{ entries, total, page, pageSize, anchorFile, anchorIndex }`：先过滤再切片；页码越界宿主钳制后回传；entries 带 `anchored` 标记；pageSize 默认 5                                                         |
| `history/clear`    | `{ cwd? }`                           | 空；截断 history.jsonl 并同时解除锚点                                                                                                                                                                    |
| `anchor/set`       | `{ cwd?, file }`                     | 当前锚点文件名；文件名非法 `INVALID_PARAMETER`、目标图不存在 `NOT_FOUND`                                                                                                                                 |
| `anchor/unset`     | `{ cwd? }`                           | 空（幂等）                                                                                                                                                                                               |
| `test-connection`  | —                                    | `{ ok, reason?, detail? }`；reason ∈ `missing-key` / `invalid-key`（401 或 InvalidApiKey）/ `gateway`（网络异常）/ `unknown`（未识别的网关响应，附 detail 灰态展示）；空体 POST 鉴权探测，不消耗生成配额 |

错误约定：与提供方 resolver 一致的可判定错误码，不做隐式默认值兜底。

## 5. i18n

- 面板全部可见字符串进双语字典（zh/en），沿用现有 `locale.register(NS, { zh, en })` 与回退链；
- 新增词条统一以 `panel.` 前缀命名空间管理，避免与工具卡片词条冲突。

## 6. 验收标准

1. DSH web profile 设置窗口出现「UI 草图」入口，4 页内容与本文一致；
2. 修改偏好在重开会话后仍生效（持久化验证）；
3. 设为锚点后，不带 reference 的 `ui_mockup` 调用实际走 I2I（provider 收到参考图）；
4. 清空历史后锚点同步解除，`history.jsonl` 归零且图片仍在磁盘；
5. 语言切换实时生效，无双语长度溢出破坏布局；
6. 单元 + 组合测试、typecheck、lint、build 全绿。
