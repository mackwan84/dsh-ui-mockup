# v0.3.0 Installation And Configuration P0 Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 关闭 REL、SW3、URL、KEY、PRV、PREF、MDL 共 20 条未关闭 P0。

**Architecture:** 用干净安装、0.2.0 升级、F13 配置异常和专用凭据四类隔离环境复用证据；配置写前写后都保存脱敏快照，UI 与运行时状态双向核对。

**Tech Stack:** pnpm pack、npm、DSH CLI/Web、YAML fixtures、Codex In-app Browser。

**Spec:** `docs/testing/v0.3.0/browser-cases.md` 的 REL、SW3、URL、KEY、PRV、PREF、MDL。

## Global Constraints

- 安装证据必须来自 tarball，不使用源码 link 代替 REL-01/REL-02。
- 升级环境先运行 0.2.0 并通过 UI 生成偏好、历史、锚点和图片，再原地升级 0.3.0。
- F13 每个异常使用独立 home；畸形 YAML、目录占位、写拒绝和 HMR pending 不串场。
- 凭据日志只记录 configured/source/writable/hasAuth，不记录值。
