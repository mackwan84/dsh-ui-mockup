# v0.3.0 Provider And Protocol P0 Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 关闭 GEN、OAI、FPR、TXT 共 14 条未关闭 P0。

**Architecture:** 真实 Provider 证明端到端可用，F14～F17 证明协议与错误边界；同一浏览器会话贯穿工具结果、图片卡片、历史、确认和规格锁定。

**Tech Stack:** 三家图像 Provider、Node.js fixture gateway、DSH Web、Codex Browser、JSONL request trace。

**Spec:** `docs/testing/v0.3.0/browser-cases.md` 的 GEN、OAI、FPR、TXT。

## Global Constraints

- 桩结果不能替代三家真实生成。
- OpenAI 兼容真实网关必须支持至少一种 b64/url，并准备支持 n=2/3/4 的网关关闭数量边界。
- 请求日志只记录字段名、模型、n、size、状态和 hasAuth；不记录 Authorization 值和完整用户数据。
- 图片质量样本使用固定描述、尺寸和 Provider，不挑选最好结果替代整组。
