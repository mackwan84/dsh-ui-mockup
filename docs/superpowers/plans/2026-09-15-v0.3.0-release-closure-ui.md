# v0.3.0 UI Main Flow P0 Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 关闭 ANN、CARD、ANC、UX 共 13 条未关闭 P0。

**Architecture:** 以固定单图/多图真实资产建立卡片→标注→反馈→确认→锚点完整流程；用真实键盘和指针在中英、浅深与两个桌面视口执行。

**Tech Stack:** DSH Web、Codex In-app Browser、固定 PNG/JPEG/WebP、浏览器截图与 DOM/AX 证据。

**Spec:** `docs/testing/v0.3.0/browser-cases.md` 的 ANN、CARD、ANC、UX。

## Global Constraints

- 合成 PointerEvent 只用于诊断，不关闭真实指针 P0。
- 所有图像必须能真实解码，不能用空白或损坏文件替代健康样本。
- 视口固定为 1024×800 和 1440×900；原生缩放与 CSS zoom 不混用。
- 英文宿主不可用时 UX-01 保持阻塞，除非版本范围在执行前正式调整。
