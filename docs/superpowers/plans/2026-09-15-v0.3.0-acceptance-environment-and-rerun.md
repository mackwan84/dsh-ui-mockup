# v0.3.0 Acceptance Environment And Rerun Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在隔离 DSH 环境中复用并扩展 F01～F17，使用 Codex 内置浏览器重新执行可关闭用例并生成可信的197条状态台账。

**Architecture:** Provider 桩、隔离 home、配置快照和浏览器证据全部留在 `.artifacts/`。执行环境消费产品修复计划产生的唯一提交，不触碰个人 DSH 配置或当前 CRM 资产；报告从逐项台账汇总，不手工维护重复计数。

**Tech Stack:** Node.js HTTP server、DSH Web、Codex In-app Browser、CDP 网络事件、Markdown、JSONL。

**Spec:** `docs/superpowers/specs/2026-09-15-v0.3.0-acceptance-repair-design.md`
