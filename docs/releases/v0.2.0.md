## 本版本内容

- **M5 标注式精准反馈**：卡片图片点击进标注弹窗（默认“选择/移动”平移与选择、矩形/画笔/箭头、显式删除按钮与键盘删除、自动编号、适合窗口与50%/100%/150%/200%缩放、三色、

  `baseImage` 标注图硬防护；纯几何模块 `src/annotation.ts`（node 环境单测）；
- **M6 生成加速**：`fastPreview` 方向稿参数（仅 high-fidelity 生效；与线框组合忽略并说明）、
  `draftModel` 方向稿模型档（解析顺序：显式 model → draftModel → wireframeModel → Provider 默认）、
  历史 `fastPreview` 字段 + 「方向稿」标签 + 「只看方向稿」服务端过滤、方向稿设锚一次性提示、
  「按这版精修」按钮（仅 `high-fidelity + fastPreview=true` 可见；线框即使原始参数带
  `fastPreview=true` 也不显示）；
- **M7 火山多图并发**：未合入——本机无 `ARK_API_KEY`，无法按提案门槛制实测（耗时改善 ≥30%
  且 429 不增），保持串行；后续具备凭据时补测再议；
- **S0 结论**：`createDraftImages` 三档判定为第 ② 档（运行时可用、类型面未公开），0.2.1
  标注图附件路径附退出条件；百炼 API 编辑能力作为 0.2.1 候选，但 0.2.0 插件编辑调用明确返回
  `NOT_IMPLEMENTED` 并回退整体重生成；`enable_thinking` 开关存在（落地与否待产品决策），见
  `docs/references/dashscope-image-edit-and-thinking-mode.md`。

### 代码审查后修复（2026-09-10）

全量验收与质量修复之后又做了一轮三视角代码审查（完整性 / 正确性 / 影响面），无致命问题，
修复 8 项并补回归：

- **`fastPreview` 使用规则缺失**：方向稿的使用时机与「确认后同一描述去掉 `fastPreview` 跑精修档」
  此前只存在于工具 schema 字段描述，`ui-mockup-usage` 提示词未提及，M6 主路径依赖模型自行推断；
  现补一条与标注反馈对称的使用规则；
- **历史页「只看方向稿」脱同步**：工作区/连接变化时 effect 拉全量列表但不复位勾选态，
  造成「显示已过滤、列表却是全量」且后续翻页 total/page 错位；现过滤位与请求参数一同复位；
- **标注弹窗提交按钮静默无效**：`submit()` 防御 `imageSize === null` 但按钮只禁用空意见，
  大图加载期间可点却什么都不发生；现两个守卫口径一致；
- **`projectMark` 箭头分支除零**：矩形/画笔经 `markBounds` 对非法尺寸返回 null，
  箭头直接除以 `imageWidth` 会产出 `NaN` 文本并进入模型可见消息；现三种工具同口径；
- **模型页候选说明漏档**：三个模型档控件只有线框/高保真两档说明；现补齐方向稿候选；
- **`NETWORK_ERROR` 过宽**：两家 Provider 把所有非取消非超时异常一律包成网络错误，
  会把编程错误（如非法 header 值）标成网络问题误导排障；现收紧为 undici 传输失败（`TypeError`），
  其余原样上抛；取消仍原样上抛、超时仍为 `TIMEOUT` 不变；
- **删除键作用域比文档宽**：原实现是「目标不是输入控件即删」，焦点在工具条按钮上也会删标记；
  现收紧为仅画布自身聚焦时生效，与「聚焦画布时」的文档描述对齐；
- **标记快照栈无上限**：连续画笔每笔一份全量快照，只增不减；现限为 50 层。

回归净增 7 项（`pnpm test` 197 → 204）：三工具非法图像尺寸均返回 null、两家 Provider 非传输类
异常原样上抛、底图未就绪时提交按钮禁用、焦点在按钮上时删除键不删标记、过滤位随连接变化复位、
模型候选说明覆盖三档；并在 `composition.spec.ts` 对提示词规则新增方向稿断言。
本轮只改代码与测试，未引入依赖；错误码集合、历史 schema 与工具参数契约均未变。
