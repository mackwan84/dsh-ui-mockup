# 对外文档双语治理

> 状态：已生效  
> 生效日期：2026-09-17  
> 适用范围：仓库中面向 GitHub、npm 使用者与外部集成开发者的 Markdown 文档。

## 目标

让中文使用者与国际 npm 使用者获得语义等价、可互相跳转的使用与集成信息，同时不把验收过程、临时计划和原始证据误当作公开产品资料。

## 对外双语范围

| 类别               | 中文入口                                                | 英文入口                                                      | 维护方式                                 |
| ------------------ | ------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------- |
| 项目入口           | `README.md`                                             | `README.en.md`                                                | 同一提交同步更新                         |
| npm 包说明         | 各包 `README.md`                                        | 同目录 `README.en.md`                                         | 在两份 README 顶部互链                   |
| 文档导航           | `docs/README.md`                                        | `docs/README.en.md`                                           | 列出各自语言的公开资料                   |
| 产品指南           | `docs/guides/*.md`                                      | `docs/en/guides/*.md`                                         | 路径镜像，中文为既有稳定路径             |
| 架构与外部参考     | `docs/architecture/overview.md`、`docs/references/*.md` | `docs/en/architecture/overview.md`、`docs/en/references/*.md` | 技术语义、版本和来源必须一致             |
| 当前及后续发布记录 | `docs/releases/vX.Y.Z.md`                               | `docs/en/releases/vX.Y.Z.md`                                  | 发布状态必须逐字义等价，不得提前宣称发布 |

## 不在双语公开范围内的资料

- `docs/testing/` 的浏览器用例、测试数据与验收过程；
- `docs/superpowers/` 的临时设计、计划与执行记录；
- `AGENTS.md`、原始截图、服务响应、日志及 `.artifacts/`；
- 仅供维护者排障的细节。必要时应在公开文档提供简短、去敏的结论，而不是复制原始材料。

## 语言与素材规则

1. 每份对外文档开头提供显式语言切换链接；链接使用相对路径。
2. 代码、包名、命令、配置键、错误码、版本号、URL 与 Provider 名称不翻译；说明文字翻译时不得改变其语义。
3. npm 仅自动展示包根目录的 `README.md`，因此中文 README 必须链接英文版，英文 README 必须链接中文版。
4. 对外文档使用的 UI 截图必须与该文档语言一致。不得在英文页面中复用含中文 UI 文字的截图；原始采集证据留在 `.artifacts/`，压缩后的长期素材放在 `docs/assets/`。
5. 修改用户行为、公开 API、默认值、Provider 能力、错误语义或发布状态时，必须在同一提交更新两种语言的相应文档。

## 验收

1. 每个公开中文入口都能到达等价的英文入口，反向亦然。
2. 两种语言的安装命令、配置键、支持范围、版本与发布状态一致。
3. 所有 Markdown 本地链接可解析，并通过 `pnpm format:check`。
4. 文档不包含密钥、用户路径、原始服务响应或仅适用于内部验收的结论。
