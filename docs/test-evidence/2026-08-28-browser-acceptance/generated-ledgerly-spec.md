# Ledgerly 登录页设计规格

- 设计稿基准:`design/images/mockup-1787910751814-3d5e0fc1-2.jpg`(用户已确认)
- 平台:Mobile(竖屏,基准画幅 1152×2048,按 375pt 逻辑宽度实现)
- 页面语言:英文

## 配色

| 用途                           | 色值(近似,以实现时取色为准) |
| ------------------------------ | --------------------------- |
| 主色 Primary(按钮、字标、链接) | `#1E7BF0` 左右的亮蓝色      |
| 页面背景                       | `#FFFFFF`                   |
| 标题文字                       | `#111418` 近黑色            |
| 次要文字(副标题、提示)         | `#6B7280` 灰色              |
| 输入框边框                     | `#E5E7EB` 浅灰              |
| 输入框填充                     | `#FFFFFF`                   |
| 主按钮文字                     | `#FFFFFF`                   |
| 第三方按钮                     | 白底、浅灰边框、深色文字    |

## 字体与排版

- 字体:系统无衬线(iOS 用 SF / Android 用 Roboto,Web 可用 Inter)
- Welcome back 标题:约 34pt,字重 700,居中
- 副标题:约 15pt,字重 400,灰色,居中
- 品牌字标 "Ledgerly":约 30pt,字重 700,主色蓝色
- 输入框浮动标签:约 13pt,灰色
- 主按钮文字:约 17pt,字重 600
- 链接文字(Forgot password? / Create account):主色蓝色,字号约 14pt

## 间距与圆角

- 页面左右安全边距:24px
- 输入框高度:约 56px,圆角 12px,带轻微卡片阴影(方案二特征:输入区为带阴影的白色卡片分组)
- 输入框之间垂直间距:约 16px
- 主按钮高度:约 54px,圆角 14px,全宽
- 第三方按钮高度:约 50px,圆角 12px,两个按钮横向等宽排列,间距 12px
- 各区块(Logo / 标题 / 表单 / 按钮 / 第三方 / 注册入口)之间垂直间距:24–32px

## 组件清单

1. **状态栏**:系统状态栏(时间、信号、电池),占位即可
2. **品牌区**:蓝色圆角方形钱包图标 + "Ledgerly" 蓝色字标,居中
3. **欢迎区**:"Welcome back" 大标题 + "Sign in to manage your money smarter." 副标题,居中
4. **Email 输入框**:卡片式容器,浮动标签 "Email",左侧信封图标,占位文字 "you@example.com"
5. **Password 输入框**:卡片式容器,浮动标签 "Password",左侧锁图标,右侧眼睛(显示/隐藏)图标
   - ⚠️ 设计稿中占位文字渲染有误("poomone"),实现时使用掩码圆点 `••••••••` 或空占位
6. **Forgot password? 链接**:右对齐,位于密码框下方
7. **主登录按钮**:全宽蓝色 "Log in" 按钮
8. **分隔线**:左右细线 + 中间灰色文字 "or continue with"
9. **第三方登录**:并排两个描边按钮,"Continue with Google"(彩色 G 图标)与 "Continue with Apple"(黑色 Apple 图标)
10. **注册入口**:底部居中 "New to Ledgerly? Create account","Create account" 为蓝色链接
