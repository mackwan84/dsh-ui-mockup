## 1. 执行范围与判定口径

### 1.1 本轮变更追踪（v0.3.0）

| 变更                   | 内容                                                                                                    | 影响面                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 供应商元数据表收敛     | 消费方全部提供方专属事实收敛为单一注册表（prefactor，对外行为零变化）                                   | 设置面板、切换、探测、凭据映射 |
| openai-compat Provider | `POST {baseUrl}/images/generations` 最小子集（model/prompt/n/size）、双格式归一、尺寸透传、错误方言矩阵 | 新提供方                       |

| baseUrl 连接卡         | 仅 openai-compat 显示；编辑→写用户层 patch config 节（restates 全部键）→热重载落位；空值时测试连接置灰  | 面板、RPC                      |
| 模型发现               | 模型分层改组合框（input+datalist）：静态 hints ∪ `/v1/models` 建议，失败静默降级，永远可手填            | 面板、RPC                      |
| 升版                   | 全仓 6 包锁步 0.3.0（新包以 0.2.0 入库后随批升版）                                                      | 发布元数据                     |

### 1.2 判定口径

- **功能判定**：按用例的预期结果逐条核对；错误形态用例以**错误码与消息可判定**为准（不是"报错即失败"）。
- **出图质量判定**：沿用 0.2.0 主观质量标准——要求元素齐全（按描述逐项检查）、无文字乱码到不可读、
  无明显截断/畸形/水印；线框档须为黑白低保真风格。
- **确定性数据**：生成描述统一使用 `data/crm.json` 中的 CRM 场景（与 0.2.0 相同），
  保证多轮执行可比。

### 1.3 必须遵守的边界

- 浏览器用例在 DSH 宿主真实浏览器界面执行；不得用 DOM 快照或组件单测替代。
- openai-compat 用例需一个真实 OpenAI 兼容网关（one-api/new-api 均可）与有效凭据；
  网关地址、模型名按环境填写并记录。
- 全量回归沿用 0.2.0 手册的公共操作与记录要求。

## 4. 0.3.0 增量验收用例

### 4.1 三提供方装配与切换（P0）

| #     | 用例               | 操作                                          | 预期                                                                      |
| ----- | ------------------ | --------------------------------------------- | ------------------------------------------------------------------------- |
| SW-01 | 三卡渲染           | 打开 设置 · UI 草图 · 提供方与模型            | 三张卡片（百炼/火山/OpenAI 兼容网关）由元数据表渲染，当前生效方选中态正确 |
| SW-02 | 切到 openai-compat | 点击第三张卡                                  | 卡片切换选中；几秒内落位；模型分层默认被重置为「跟随提供方默认」          |
| SW-03 | 切回百炼           | 再点第一张卡                                  | 同上语义，往返切换无残留                                                  |
| SW-04 | 未就绪错误         | openai-compat 生效且未配置地址/凭据时直接生成 | 明确错误（`INVALID_PARAMETER`/`MISSING_CREDENTIAL`），消息含可操作指引    |

### 4.2 连接配置卡（P0）

| #     | 用例         | 操作                                  | 预期                                                                              |
| ----- | ------------ | ------------------------------------- | --------------------------------------------------------------------------------- |
| CN-01 | 卡片出现条件 | 分别在百炼与 openai-compat 生效时查看 | 仅 openai-compat 显示连接配置卡                                                   |
| CN-02 | 回显         | openai-compat 生效且部署层已配地址    | 输入框回显生效地址；帮助文案提示 `/v1` 习惯                                       |
| CN-03 | 保存落位     | 输入合法地址保存                      | 写入用户层配置并热重载，几秒内生效；用户层 patch 该行 config 含全部键（restates） |
| CN-04 | 非法值       | 输入 `ftp://x` 保存                   | 客户端即拒绝并提示，不发 RPC；不落盘                                              |
| CN-05 | 置灰联动     | 地址为空                              | 「测试连接」置灰；配置后恢复                                                      |
| CN-06 | 测试连接     | 配置真实网关与 key 后点击             | 401→密钥错误；400/429→连接正常（与既有两家同语义）                                |

### 4.3 模型发现与手填（P0/P1）

| #     | 用例     | 操作                                      | 预期                                               |
| ----- | -------- | ----------------------------------------- | -------------------------------------------------- |
| MD-01 | 建议合并 | openai-compat 生效，网关可拉 `/v1/models` | 组合框候选 = 静态推荐 ∪ 网关列表（去重）；三档一致 |
| MD-02 | 降级     | 地址缺 `/v1`（HTML-200）或网关不可达      | 静默降级：候选只剩静态推荐，**无错误弹窗**         |
| MD-03 | 手填     | 任意档位直接输入自定义模型名              | 可保存并被后续生成使用                             |
| MD-04 | 跟随默认 | 清空三档                                  | 生成时回落 Provider 分层默认（未预置则明确报错）   |

### 4.4 生成闭环与错误形态矩阵（P0）

按「模型 × 返回形态 × 错误形态」采样执行；每格至少 1 次，记录原始响应片段。

| #         | 场景                                              | 预期                                                                   |
| --------- | ------------------------------------------------- | ---------------------------------------------------------------------- |
| GEN-01    | 正常生成（b64_json 网关，gpt-image 系）           | 出图落资产库；比例与请求一致（`1280*720` → 16:9 横版）                 |
| GEN-02    | 正常生成（url 返回形态网关，如代理百炼/方舟模型） | 图片立即下载转存；url 不持久化                                         |
| ERR-01    | 模型不存在（new_api 系 503）                      | `HTTP_ERROR` 透传 503 与 `model_not_found` 码                          |
| ERR-02    | `n>1` 被网关拒绝（400）                           | `INVALID_PARAMETER` 透传原始消息；`n=1` 重试成功                       |
| ERR-03    | 错误 key（401）                                   | `MISSING_CREDENTIAL`，面板测试连接同判                                 |
| ERR-04    | 地址缺 `/v1`（HTML-200）                          | `BAD_RESPONSE`，消息含响应片段与「核对 baseUrl」提示                   |
| ERR-05    | 限流（429）                                       | `RATE_LIMITED` 上报，**无自动重试**（与百炼/方舟策略不同，属设计决策） |
| ANCHOR-01 | openai-compat 生效 + 已设风格锚点                 | 锚点被跳过注入，结果消息说明「提供方不支持参考图」                     |
