# 0.2.0 浏览器回归用例

> 适用版本：0.2.0。执行环境要求：桌面 ≥1024px（正式验收基线）、DSH Web profile、
> 至少一个图像凭据（`DASHSCOPE_API_KEY` 或 `ARK_API_KEY`）。
> 结构沿用 [0.1.3 用例手册](../v0.1.3/browser-cases.md) 的分组方式；0.1.3 未变更行为
> 的回归继续引用该手册，本册只列 0.2.0 新增与变更点。

## ANN：标注弹窗（M5）

| 用例                          | 步骤                                 | 期望                                                                                                                   |
| ----------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| ANN-01 / P0 / 点图进弹窗      | 生成一张图后点击卡片图片             | 弹窗打开，底图完整显示（原始分辨率缩放至窗口），工具栏含矩形/画笔/箭头、三色、撤销/清空、1x/2x                         |
| ANN-02 / P0 / 矩形标注 + 提交 | 选矩形，在图上拖出框，填意见，提交   | 消息含「对 design/images/<名> 的标注反馈（ISO 时间戳）：编号区域（归一化坐标）：①区域 x:[…] y:[…]。意见：…」；弹窗关闭 |
| ANN-03 / P0 / 多标记编号      | 依次画矩形、箭头、画笔各一条         | 图上出现 ①②③ 徽标；消息按工具类型投影（区域 / 从…指向… / 笔迹外接框），编号位次与创建顺序一致                          |
| ANN-04 / P1 / 撤销与清空      | 画两条 → 撤销 → 清空                 | 撤销移除最后一条；清空全部移除；无标注时两按钮禁用                                                                     |
| ANN-05 / P1 / 1x/2x 切换      | 滚动到图像中部，切 2x，再切回 1x     | 2x 后视口中心保持不变；回到 1x 恢复                                                                                    |
| ANN-06 / P1 / 三色切换        | 分别用红/黄/蓝画一条                 | 叠层颜色与所选一致；徽标底色同步                                                                                       |
| ANN-07 / P0 / 无标注退化      | 不画任何标记，只填意见提交           | 发出与「提交修改意见」同款的纯文字反馈消息（不含编号区域段）                                                           |
| ANN-08 / P0 / 空意见禁提交    | 画了标记但意见留空                   | 提交按钮禁用                                                                                                           |
| ANN-09 / P1 / Esc 与焦点陷阱  | 打开弹窗后按 Esc；反复按 Tab         | Esc 关闭；Tab 焦点在弹窗内循环不外逃                                                                                   |
| ANN-10 / P1 / 英文界面        | 切英文后打开弹窗                     | 控件文案英文；提交的消息仍为固定中文模板                                                                               |
| ANN-11 / P2 / 图片加载失败    | 用无效路由参数打开弹窗（构造 404）   | 弹窗显示加载失败提示与取消按钮，不白屏                                                                                 |
| ANN-12 / P1 / 编辑链路分离    | 对已生成图标注提交，agent 走编辑模式 | `baseImage` 传原图语义路径；模型编造标注图路径时收到「标注图不在资产库…」可操作错误                                    |
| ANN-13 / P1 / 多轮标注        | 同一张图先后提交两轮标注             | 第二轮消息时间戳更晚；agent 按最新一轮处理                                                                             |

## FPR：方向稿与精修（M6）

| 用例                         | 步骤                                     | 期望                                                                                                                                 |
| ---------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| FPR-01 / P0 / 方向稿生成     | 让 agent 以 `fastPreview` 出高保真方向稿 | 使用面板「方向稿模型」档（未配置时回落线框档）；结果消息含「方向稿」「精修」字样                                                     |
| FPR-02 / P0 / 精修按钮       | 方向稿结果卡                             | 显示「按这版精修」按钮；点击发出固定中文消息「请按 design/images/<名> 这一版方向精修：同一描述，改用精修档（不要传 fastPreview）。」 |
| FPR-03 / P1 / 按钮可见性     | 普通高保真结果卡 / 线框结果卡            | 均不显示「按这版精修」按钮                                                                                                           |
| FPR-04 / P1 / 线框档忽略     | `fidelity='wireframe'` + `fastPreview`   | 正常出线框图；结果消息含「线框档本身已是快模型, 已忽略 fastPreview」                                                                 |
| FPR-05 / P1 / 历史标记与过滤 | 生成方向稿后进设置 · 生成历史            | 该条带「方向稿」标签；勾选「只看方向稿」后列表只剩方向稿条目；取消勾选恢复                                                           |
| FPR-06 / P1 / 方向稿设锚提示 | 在方向稿卡片点「设为锚点」               | 设锚成功且卡片显示琥珀色提示（内容含「方向稿」）；普通图设锚无提示                                                                   |
| FPR-07 / P2 / 模型档配置     | 面板「提供方与模型」设置方向稿模型并重置 | 新增「方向稿模型（fastPreview）」行可选可存；「重置模型默认」同时清三档                                                              |
